# 岗位-简历人岗匹配推荐系统

> 行业大数据分析实践（23大数据班 · 精工1-508实训机房5 · 3周集中实训）
> GitHub 仓库：`https://github.com/zhengqing798/zq` ｜ 选题方向：招聘就业

## 1. 项目一句话

以**招聘就业**行业数据为主线：爬取真实**岗位**数据，让用户提交/粘贴一份**简历**，
系统给出「**人岗匹配评分 → 岗位推荐 → 岗位画像聚类 → 智能问答 Agent**」的完整推荐链路。

## 2. 四个业务问题（对应 Excel 课程主线）

| # | 业务问题 | 技术路线 | 对应任务 |
|---|---------|---------|---------|
| ① | 岗位/简历**质量评分** | 特征工程 + Logistic/SVM/RandomForest/XGBoost | 任务4+5（评分模型） |
| ② | **人岗匹配**与岗位推荐 | TF-IDF + 余弦相似度 + 加权匹配分公式 | 任务6（人岗匹配） |
| ③ | **岗位聚类**画像与多模型对比 | K-Means + 肘部法/轮廓系数 + PCA/t-SNE | 任务7+8（聚类/对比） |
| ④ | **大模型应用**：RAG 问答 + Agent 交互 | 向量库(Chroma/FAISS) + Function Calling | 任务10（Agent） |

## 5. Git 协作规范（团队共用）

```bash
git status                                   # 查看改动
git add <文件>                               # 暂存
git commit -m "任务1: 需求分析文档"           # 提交（写清“任务X: 干了什么”）
git pull --rebase origin main                # 推前先同步他人改动
git push origin main                         # 推送
```

- 提交信息建议带任务号：`任务2: 完成51job爬虫分页抓取`
- `.env`、API Key、`.venv/`、浏览器 profile（`.zhaopin_profile/` 等）**一律不入库**（已在 .gitignore 中处理）；`data/` 下的原始、清洗、特征与划分结果**均已入库**，便于答辩核验与复现
- 每人每天至少一次 commit + push，最终答辩会核验 **Git 提交记录**

## 6. 数据合规声明

- 仅采集**公开的招聘岗位信息**，不采集求职者个人敏感信息；
- 控制请求频率（间隔+随机 UA+失败重试），尊重目标网站 robots 与服务条款；
- 简历数据若需测试，优先使用**脱敏/模拟简历**。
