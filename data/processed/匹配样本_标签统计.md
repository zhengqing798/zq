# 匹配样本标签统计报告

> 岗位-简历人岗匹配推荐系统 ｜ 任务5 步骤1：标签构造（连续 0–100 分）
> 输入：`data/processed/zhaopin_jobs_cleaned_seg.csv`（8,836 岗位）、`简历数据_cleaned.csv` + `简历数据_seg.csv`（500 简历）
> 输出：`data/processed/匹配样本_标签数据.csv`（207640 行）、`技能标签黑名单.csv`、本报告 ｜ 随机种子 42

## 〇、标签口径（本报告全部数字均基于此口径）

| 维度 | 权重 | 算分规则 |
|---|---|---|
| 技能 | 0.30 | `0.7 × 岗位技能覆盖率 + 0.3 × 简历技能利用率`。岗位技能要求集合 = 岗位 `技能标签`（**剔除福利类 247 个 + 行业类 511 个标签**）∪ 职位描述中出现的简历技能池词；匹配前做保守档同义词归一；**集合为空 → 0 分**（无技能证据即视为不匹配，不给中性分） |
| 经验 | 0.20 | 满足岗位下限 → 100；不足 → `100 × 简历年限 / 下限`（**超资历不惩罚**）；岗位"不限" → 100；`经验要求` 错位/空值（A2，2,182 个岗位）→ 中性 60 |
| 学历 | 0.15 | 超学历不惩罚；差 1 档 60 分、差 2 档 30 分、差 3 档以上 0 分；岗位学历要求为空 → 100 |
| 地域 | 0.15 | 同城 100；跨城按城市中心直线距离：≤100km 85 分、100–300km 60 分、>300km 30 分 |
| 薪资 | 0.12 | 岗位上限 ≥ 简历期望下限 → 100；否则 `100 × 岗位上限 / 期望下限`；期望"面议" → 80（无偏好）；岗位薪资缺失 → 60 |
| 专业证书 | 0.08 | （专业项 + 证书项）/ 2。专业命中岗位名称或描述 → 100，未命中 → 40（底分）；证书技术方向命中 → 100、仅通用证书 → 70、无有效证书 → 60（底分） |

- **标签噪声**：随机 10% 的配对叠加 N(0, 6)（截断 ±15）后 clip 到 [0,100]；同时保留 `总分_规则` 纯净分作对照。
- **二分类阈值**：`总分(0-100) ≥ 65` 记为匹配。
- **候选配对**：同城对全量 + 每份简历抽样 150 个跨城对（种子 42）。

## 四、口径敏感性审计

### 4.1 岗位技能标签口径（主口径：福利类 + 行业类标签都不计入技能要求）

- 标签全量 **4724** 个（字符串去重口径）：福利待遇 **247** 个、行业领域 **512** 个（**两类都不计入“岗位技能要求”**，但岗位表中原值保留）、技能 **3965** 个。
- 归一后去重：福利待遇 **247** 个、行业领域 **511** 个。
- 福利标签覆盖岗位标签出现次数约 **1113** 次（同一标签在多个岗位上重复计数）。
- 各口径技能分对比：

| 技能分口径 | 均值 | 中位数 |
|---|---|---|
| **A 主口径（福利 + 行业标签都剔除 + 保守同义词归一）** | 4.26 | 0.00 |
| B 只剔福利标签（上一版口径） | 4.05 | 0.00 |
| C 标签一个都不剔 | 3.99 | 0.00 |
| D 剔除福利 + 行业标签但不做同义词归一 | 4.23 | 0.00 |

| 总分口径 | 均值 | 中位数 | 正样本率(≥65) |
|---|---|---|---|
| A 主口径 | 53.99 | 54.27 | 16.48% |
| B 只剔福利 | 53.92 | 54.20 | 16.26% |
| C 一个都不剔 | 53.91 | 54.17 | 16.19% |
| D 不归一 | 53.98 | 54.27 | 16.44% |

> **口径修订说明**：上一版口径把“岗位技能要求集合为空”当作信息缺失、给中性 60 分。该规则让 22102 个配对（10.64%）凭空拿到 60 分（高于 99.4% 的其余配对），并使若干**无技能标签的无关岗位**（如连锁KTV门店店长、制程质量工程师）以 93–99 分排到榜首。现改为 **0 分**（无技能证据即视为技能不匹配），并把行业类标签一并排除出技能要求集合。
> 两项修订相互作用：上一版测算中“剔除行业标签”带来的技能分均值提升（6.30 → 10.65）主要来自“空集合吃 60 分中性分”这一副作用；改为 0 分后，主口径与只剔福利口径的技能分差距仅 **+0.21** 分。剔除行业标签在概念上仍然更正确（行业词不是技能要求），故保留为主口径。

### 4.2 同义词归一

- 保守档生效映射 **111** 条；宽松档 **6** 组仅登记未应用（见 `技能同义词表.csv`）。
- 归一使技能分平均变化 **+0.03** 分（主口径 4.26 → 不做归一 4.23）；差异很小，说明保守档只修正了少量写法差异。
- 技能覆盖率均值 5.16%、简历技能利用率均值 3.84%（仅统计岗位技能要求集合非空的配对）。

### 4.3 标签噪声

- 随机 **10%** 的配对叠加 N(0, 6)（截断 ±15）：实际扰动 **20780** 对（10.01%）。
- 噪声带来的总分变化：MAE 0.48 分、最大 15.00 分；正样本率 16.48% → 16.72%。
