# Vue3 前端（web/）—— 答辩主秀版本

> 与 `src/web/app.py`（Streamlit 版）**共用同一套 FastAPI 后端**（33 个接口），
> 二者是**同一系统的两种前端实现**：Streamlit 作为保底交付与接口验证，Vue3 作为视觉与交互主秀。

## 技术栈

| 项 | 选型 |
|---|---|
| 框架 | Vue 3（`<script setup>` + TypeScript） |
| 构建 | Vite |
| UI 库 | **Element Plus**（中文文档全、组件最全、最接近国内招聘网站观感） |
| 图表 | **ECharts**（六维雷达、簇规模环形图） |
| 路由 / 状态 | Vue Router（hash 模式）+ Pinia |
| 请求 | axios（统一拦截器：自动带 Bearer 令牌、401 自动跳登录、错误统一提示） |
| 配色 | 参考 **BOSS直聘**：主色青绿 `#00A6A7`，薪资橙 `#FF6A00`，浅灰底 + 白卡片 |

> **导航与入口约定（2026-09-18 改版）**：
> 顶部标签只有 **首页 ｜ 岗位 ｜ 公司**（游客可见），登录后追加 **岗位推荐**；**个人中心只从右上角用户下拉进入**（无标签）；
> **简历没有独立页面**——粘贴正文 / 上传 PDF / 解析 / 保存都在个人中心的「我的简历」页签里，解析完一键去「岗位推荐」；
> **岗位详情是独立页面**：每个岗位一个 URL（`#/job/J0020`），从首页/岗位列表/公司页/匹配结果的任意一处点岗位都跳过去，**不再弹右侧抽屉**。
> 页面里会展示"与我简历的匹配"（本次会话做过匹配时）与该公司的其他在招岗位。
>
> **问答里的岗位链接可点**：回答中提到具体岗位时会给出 `[岗位名](/#/job/J0020)` 形式的链接（Prompt v7 要求），
> 悬浮球把它渲染成可点链接（先转义 HTML 再替换白名单链接），点击直达岗位页并自动收起对话框。
>
> 旧地址 `#/resume` 自动重定向到个人中心。**智能问答已改为全局悬浮球**（`ChatWidget.vue`）：右下角可拖动的球，
> 单击弹出小对话框提问并看检索结果与来源，位置记在 `localStorage`，每个页面都能用；独立的 `#/chat` 页已取消。
> 已删除的页面：`ClustersView.vue`（岗位聚类）、`ResumeView.vue`（并入个人中心）、`JobsView.vue`（改名 `MatchView.vue` 挂到 `/match`）、`ChatView.vue`（改为悬浮球组件）。
> 个人中心页签：我的简历 / 我的收藏 / 账号设置（问答记录、匹配历史两个页签已删除，接口保留）。
>
> **页面上不放"描述性文字"（长期约定）**：口径说明、数据来源、数据规模、已知局限、以及"这个推荐是怎么来的"
> 之类的说明文字**一律不出现在界面**上（接口仍返回、`docs/` 仍记录、测试仍守护），页面只保留功能与数据本身。
> `render-check.mjs` 会把这些字样当作"不该出现的内容"扫描全量 DOM，首页还额外禁 `排序`/`口径`/`随机抽取`/`来源：` 等。
>
> **简历只有一份**：个人中心「我的简历」页签里粘贴正文或上传 PDF → 解析 → 保存；已有简历时再保存就是**覆盖更新**（后端 `POST /api/user/resumes` 是 upsert，库里每人最多一行），
> 卡片上可以改标题、`修改`（把正文载回输入框）、`删除`、`去岗位推荐`。上传 PDF 时用解析接口返回的 `原文`（PDF 文本层）作为正文，所以 PDF 简历同样能保存。
>
> **首页两处随机推荐**：`地区推荐` 固定 Top 5、`热门企业` 固定 Top 10；**`高薪岗位推荐`** 从「薪资下限 > 10000 元/月」的
> 2,472 个岗位里、**`热门岗位推荐`** 从「今日回复数 ≥ 20」的 1,676 个岗位里**每次请求随机抽 8 个**
> （所以每次进首页都不一样，抽完仍按各自指标降序展示）。随机只发生在服务端 `/api/home`，前端无需处理。

## 运行

```bash
# 1) 先起后端（另开终端，在仓库根目录）
powershell -ExecutionPolicy Bypass -File scripts/run_api.ps1     # http://127.0.0.1:8000

# 2) 起前端
cd web
npm install                       # 已配 npmmirror 源；首次约 1~2 分钟
npm run dev                       # http://127.0.0.1:5173
```

其他命令：

```bash
npm run typecheck     # vue-tsc 类型检查
npm run build         # 产物 dist/（任务12 用 nginx 托管）
npm run preview       # 本地预览构建产物，端口 4173
npm run check:render  # 无头渲染检查（7 路由 + 悬浮球 + 游客态 + 反向断言）
npm run check:chat    # 智能问答真实性检查（强制不走缓存连问 5 个新问题）
```

> 开发期由 Vite **代理 `/api` → `http://127.0.0.1:8000`**，所以前端代码里不写后端地址；
> 容器部署时用环境变量 `VITE_API_BASE`（如 `http://api:8000`）覆盖。

## 与 Streamlit 版的关系

| | Streamlit（`src/web/app.py`） | Vue3（`web/`） |
|---|---|---|
| 定位 | 保底交付 + 接口契约验证 | 答辩主秀 |
| 启动 | `streamlit run src/web/app.py` → 8501 | `npm run dev` → 5173 |
| 依赖 | 纯 Python | Node 工具链 |
| 自动化测试 | ✅ `tests/test_web.py`（AppTest 无头执行，10 项） | ⚠️ 暂无（已用无头渲染脚本临时验证） |
| 视觉上限 | 中 | 高 |

两套前端**调同一批接口**，因此数据与口径完全一致——这正是"前端只走 HTTP"的设计收益。
