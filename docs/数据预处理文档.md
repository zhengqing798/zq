## 第二部分 本轮处理要求（用户提出）

1. **缺失值处理**：`职位描述` 列缺失（为空）的岗位 → **删除整行**；
2. **去重**：`岗位名称` + `公司名称` + `职位描述` 三列**同时相同**才判定为重复并去重；

4. **异常值处理**：先由我找出数据中的异常并汇报，**经用户确认后**再处理；
5. **文本清洗（jieba 分词）**：先说明处理方式，**经用户确认后**再执行；
6. **输出《数据预处理文档》**：需包含第一次处理与本轮处理的要求、过程与结果。

## 第五部分 文本清洗（jieba 分词）—— 已执行

### 5.1 执行流程
1. **加载自定义词典**：把技术术语与业务词加入 `jieba` 词典，避免被切错：
   `Java、Python、C++、C#、.NET、JavaScript、Vue、Spring、机器学习、深度学习、数据分析、大数据、云计算、前端、后端、运维、测试、嵌入式、算法、网络安全、数据库、微服务、分布式…`
2. **停用词表**：过滤标点、数字、单字、常见无意义词（"负责/熟悉/具有/相关/优先/以上/以及/我们/公司/工作"等）。
3. **分词**：对 `职位描述` 逐行 `jieba.lcut`，去掉停用词与长度 < 2 的词。
4. **输出（新增列，不覆盖原列）**：
   - `描述分词`：空格分隔的分词结果（供后续 TF-IDF / 词云）
   - `描述关键词Top10`：该行词频最高的 10 个词（便于人工抽检）
5. **全局统计**：输出 `data/raw/描述词频统计.csv`（词 → 词频），供词云与"岗位热门技能"分析使用。
6. **落盘方式**：生成新文件 `zhaopin_jobs_cleaned_seg.csv`，保留 `zhaopin_jobs_cleaned.csv` 不变。

### 5.2 输出与耗时
- 8,836 行 × 平均几百字：实际约 1 分钟内完成；
- 新增 2 列 + 1 个词频表文件。

复现（本轮处理的核心逻辑）：
```python
# 1) 删除职位描述为空的行
rows = [r for r in rows if (r.get('职位描述') or '').strip()]

# 2) 按 岗位名称+公司名称+职位描述 去重
seen, out = set(), []
for r in rows:
    k = (r['岗位名称'].strip(), r['公司名称'].strip(), r['职位描述'].strip())
    if k not in seen:
        seen.add(k); out.append(r)

# 3) 学历要求标准化：非学历值清空
ALLOW = {'初中','初中及以下','高中','中专','中技','大专','大专及以上','本科',
         '硕士','硕士及以上','博士','MBA','EMBA'}
for r in out:
    if r['学历要求'].strip() not in ALLOW:
        r['学历要求'] = ''

# 4) 删除薪资为空的行
out = [r for r in out if (r.get('岗位薪资') or '').strip()]

# 5) jieba 分词(新增两列, 不覆盖原描述)
import jieba
for r in out:
    toks = [w for w in jieba.lcut(r['职位描述'])
            if w.strip() and w not in STOP and TOKEN_RE.match(w.strip())]
    r['描述分词'] = ' '.join(toks)
    r['描述关键词Top10'] = '|'.join(w for w, _ in Counter(toks).most_common(10))
```
